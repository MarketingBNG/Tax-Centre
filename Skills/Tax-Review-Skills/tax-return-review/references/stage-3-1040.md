# Stage 3 — Form 1040 (US residents)

Complex individual returns (GILTI, PFIC, treaty claims) are usually on ProConnect,
but the checks are the same. This module covers resident returns; for the
international forms themselves see `stage-3-international-forms.md`; for
non-residents see `stage-3-1040NR.md`.

## 3.1 Identity, status, residency

| Check | Plain English |
|---|---|
| Filing status supports the facts (married, dependents, head of household tests) | Status drives everything |
| Residency: substantial presence test days, first-year / last-year choices, dual-status, treaty tie-breaker — decision documented | 1040 vs 1040-NR vs dual-status is a Stage 0 decision |
| F-1 / J-1 exempt-individual years counted correctly; 8843 filed for exempt years | Days excluded |
| ITIN / SSN valid; spouse and dependents have valid TINs; ITIN renewal status | Rejections |
| State residency and part-year allocation consistent with federal | States |

## 3.2 Income

| Check | Why |
|---|---|
| W-2s, 1099s (INT, DIV, B, NEC, K, R, G), K-1s all entered and totals agree to documents | IRS matching |
| K-1 inputs: basis, at-risk, passive limits applied; codes from box 20 / 17 used | Limitation |
| Schedule C: revenue ties to 1099-K / books; expenses per Stage 1 sweep; home office; vehicle log; SE tax | Substantiation |
| Schedule E: rental income and expenses, depreciation, passive rules, foreign rental (foreign address, FBAR / 8938 implications) | Passive |
| Foreign income: Indian salary, interest, rental, dividends, capital gains reported in USD at documented rates; Form 16 / 26AS / AIS as evidence | Worldwide income |
| Foreign tax credit (1116) by basket; Indian TDS is creditable only when the tax is actually paid and the income is US-taxable in the same year; no double benefit with §911 | Credit |
| Stock options / RSU / ESPP: basis correctly adjusted; foreign employer plan reporting | Basis errors |
| Crypto question answered; 8949 for dispositions | Mandatory question |
| Sale of property (US or foreign): 8949, basis in USD at acquisition-date rate, FIRPTA for NRA | Basis |

## 3.3 Cross-border information returns — check on every 1040 with any foreign link

| Trigger | Form |
|---|---|
| Foreign accounts, aggregate > threshold at any time | FBAR (FinCEN 114) — separate filing |
| Foreign financial assets above threshold | 8938 |
| 10%+ ownership of foreign corporation (Indian Pvt Ltd) | 5471 + GILTI (8992) + Subpart F; 962 election considered |
| Foreign mutual funds, ULIPs, certain Indian funds | 8621 (PFIC) — each fund |
| Gift or inheritance from foreign person above threshold | 3520 |
| Foreign trust (including some Indian family arrangements, PPF/EPF position note) | 3520 / 3520-A |
| Foreign partnership / DRE / branch | 8865 / 8858 |
| Treaty-based position (e.g., Indian student / researcher, tie-breaker) | 8833 |
| Foreign earned income exclusion | 2555 |

Missing any of these is Critical — penalties are per form and continue to run.
Detailed form-by-form checks: `stage-3-international-forms.md`.

## 3.4 Deductions, credits, payments

| Check | Why |
|---|---|
| Itemised vs standard: 1040-NR generally cannot take the standard deduction except Indian students / apprentices under the treaty — 8833 or statement | `authority: verify` |
| SALT cap, mortgage interest limits, charitable substantiation | Limits |
| Child tax credit / dependent credits: SSN vs ITIN eligibility, residency of child | Eligibility |
| Education credits: 1098-T; NRA restrictions | Eligibility |
| Estimated payments and withholding per IRS transcript | Payments |
| Health insurance marketplace (1095-A) reconciled | Repayment |

## 3.5 1040-NR

For any non-resident, dual-status, or first/last-year individual, use
`stage-3-1040NR.md` — the residency decision is a Stage 0 decision and changes
every section above.

## 3.6 Sign-off items

1. Every information document in the file is on the return; every return entry has a document.
2. Every foreign link has its information return or a documented "not required".
3. Residency decision is written down, with day counts.
4. Refund / balance due and payment method confirmed with client instruction.
