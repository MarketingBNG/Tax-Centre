# Stage 3 — Form 1120 (C corporations), with 1120-S differences

## 3.1 Header and questions

| Check | Plain English |
|---|---|
| Boxes: initial / final / name change / address change / consolidated / PHC / Schedule M-3 required | Wrong box = wrong processing |
| Schedule K (1120 page 4): every question answered — accounting method, business code, ownership of/by entities, 20%+ owners, foreign owners (question 7 — triggers 5472), NOLs, dividends paid, foreign accounts, 5471/8858 ownership, §163(j), 8990 | Each "yes" has a consequence |
| Question 7: **any foreign person owning 25%+** — 5472 required, and Part IV of 5472 populated | See `stage-3-1120F-5472.md`; per-form penalty |
| Officer schedule (1125-E) if receipts threshold met | Officer comp detail |
| Cost of goods sold (1125-A) if inventory | Inventory method, §263A, valuation, change in method |

## 3.4 Schedule L, M-1, M-2

| Check | Why |
|---|---|
| L beginning = prior year ending | Matching |
| L agrees to Stage 1 TB | Tie-out |

| M-1: net income per books → taxable income before NOL/special deductions (line 28). Standard items: federal tax, non-deductible meals/entertainment/penalties, book vs tax depreciation, bad debt reserve, accrued bonus, prepaid, §263A | Every item named |

## 3.6 State

- Every nexus state has a return; apportionment factors agree to books; state addbacks (federal bonus, state income tax, related-party interest/intangibles) applied per Drake's state module.
- Franchise / minimum tax and annual report obligations are the obligation engine's job — confirm the engine's list matches Drake's state returns generated.

## 3.7 Sign-off items specific to 1120

1. Line 28 taxable income before NOL = M-1 line 10.
2. L line 25 retained earnings = M-2 line 8.
3. Federal tax expense per books appears on M-1 as an addback.
4. Every Schedule K "yes" has its attachment.
5. If any owner is foreign — 5472 is attached and Part IV totals agree to the ledger.

## 1120-S — differences from the above

| Item | S-corporation rule |
|---|---|
| Form 2553 acceptance letter in file; effective date; shareholder count and eligibility (no NRA shareholders, no entity shareholders except eligible trusts / single-member DREs owned by eligible persons) | A foreign or ineligible shareholder terminates the election — Critical |
| Officer compensation: **reasonable salary paid through payroll before distributions** | Most common S-corp adjustment; position note on reasonableness |
| Distributions pro-rata to ownership on the same date | Disproportionate distributions = second-class-of-stock risk |
| Schedule K / K-1: separately stated items as for 1065; box 1 total = Schedule K line 1 | Tie-out |
| AAA roll (M-2): opening + ordinary income + separately stated income − losses/deductions − distributions = closing; OAA for tax-exempt; distributions in excess of AAA are dividends if E&P exists | Basis and character |
| Shareholder basis: 7203 furnished to shareholders; losses limited to basis | Loss limitation |
| Health insurance for >2% shareholder: on W-2 box 1, deducted by corporation, reported to shareholder | Classification |
| Built-in gains tax, excess passive income if the corporation was previously a C corp | Only if history |
| §199A codes on K-1 box 17 (V) — QBI, W-2 wages, UBIA | Shareholder needs them |
| State PTE elections | Made / declined deliberately |
